<h1>Gabriel - Data Carving with XXD, Binwalk and Scalpel </h1>



<h2>Description</h2>
The difference between steganography and encryption, describe insertion and substitution-based hiding techniques including least significant bits (LSB), prepare a carrier image and secret evidence file, use Steghide to embed and extract concealed data, calculate and compare cryptographic hashes, perform a controlled password dictionary test using StegSeek, and document all activities in a repeatable forensic report.
<br />


<h2>Languages and Utilities Used</h2>

- <b>Kali Linus </b> 


<h2>Environments Used </h2>

- <b>Windows 11</b> (21H2)
